# Gym Website

A responsive gym and fitness website project built to practice modern front-end development and create a strong, conversion-focused user experience for a fitness business.

> **Project note:** This repository is a front-end website project. Any business-specific pricing, reviews, trainer profiles, transformation stories, opening hours, contact details, or performance claims shown in the demo should be verified and replaced with real information before production use.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Tailwind CSS via CDN
- AOS animations
- Lucide icons
- Responsive Web Design

## ✨ Features

- Responsive desktop and mobile layout
- Mobile navigation menu
- Hero section with clear calls to action
- Fitness services and benefits sections
- Trainer and results sections
- Pricing cards
- FAQ section
- Lead-capture form using Web3Forms
- WhatsApp contact CTA
- Smooth scrolling and scroll animations

## 🎯 What I Practiced

- Building a complete landing page from scratch
- Responsive layouts and mobile-first considerations
- Semantic HTML structure
- CSS styling and visual hierarchy
- JavaScript interactions and form handling
- Third-party frontend library integration
- Conversion-focused landing-page structure

## ⚠️ Production Checklist

Before using this as a real business website:

- Replace demo/testimonials with verified customer content
- Replace stock images with approved business photography
- Verify trainer names, qualifications, and experience
- Verify pricing, offers, opening hours, address, phone and email
- Replace placeholder social links with real profiles
- Review the form recipient/configuration and test submissions
- Verify all marketing and health/fitness claims
